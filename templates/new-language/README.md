# New language template

1. Copy this folder to `packs/<code>/` (use a [BCP 47 code](https://www.iana.org/assignments/language-subtag-registry), e.g. `sv`, `pt-BR`, `zh-Hant`).
2. Rename `Community YourLanguage.lang` to `Community <English name>.lang`.
3. In the `.lang` file change **`header`** to the name shown in the game's language menu and translate every `"value"`. Never change `"key"`. Also translate `suffixPairs` (unit suffixes like `" kts"`) and `morsePairs` (radio phrases); do **not** delete these lists, the game hangs without them.
4. Translate the tags in `Wolfpack_Data/Language/Official/English.xml` (control tooltips). Do not rename the tags. Delete the file if you do not translate it (and set `tooltips_xml` to `false`).
5. Fill in `pack.json`.
6. Run `python tools/validate.py <code>` - it must report `ok`.
7. Open a pull request (the PR template has a checklist).

Keep placeholders like `{0}` and tags like `<b>` exactly as they are. Save files as UTF-8.

## Optional: hard-coded texts (BepInEx / AutoTranslator)
Some texts are not in the `.lang` file. Easiest: translate them in the Language Tool (Editor, view *BepInEx*) and export - the tool writes the add-on folder for you. By hand: copy `addons/autotranslator` to `packs/<code>/addons/autotranslator`, rename `Translation/xx` to `Translation/<code>`, set `Language=<code>` in the ini and fill `_AutoGeneratedTranslations.txt` with your own translations.
Textures (`Translation/<code>/Texture`) are only allowed if you made them yourself; do not commit extracted game assets.
The add-on needs BepInEx 6 (IL2CPP) on the player's side (the tool can install it). You do **not** need to add the XUnity plugins: the tool installs the shared copy from the German add-on. The English source texts are listed in `reference/hardcoded-en.txt`. Delete the `addons` folder if you do not need it.
