# Hard-coded texts (not part of the .lang file)

Some texts of Wolfpack are not read from `Languages/*.lang` but are written directly into the game (scenes, code). They cannot be translated with a language pack alone. Community mods solve this at runtime with [BepInEx 6 (IL2CPP)](https://github.com/BepInEx/BepInEx) and [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator): the plugin watches every text the game shows and replaces it when the English text is listed in a file `BepInEx/Translation/<lang>/Text/_AutoGeneratedTranslations.txt` (format `English text=Translation`, `r:` lines are regular expressions).

`reference/hardcoded-en.txt` is the list of those English texts, taken from the local game files of the current version (234 texts, checked against `Wolfpack_Data` and the il2cpp metadata with the script logic described in `tools/find_strings.py`). A pack can translate them with its own add-on, see `templates/new-language/addons`.

## Where the list comes from
The candidates were collected from the file of the community project [Apade1/Wolfpack-German-Localization](https://github.com/Apade1/Wolfpack-German-Localization) (English side only) and each text was verified in our own game files. **Their translations and their texture are not part of this repository** (that repository has no license). Texts that are produced dynamically or only exist in the tooltips file are not listed.

## Not changed
Textures (images such as the `fish_1` sign) are not modified or redistributed.
