Country flags (80x48 PNG) from https://flagcdn.com (free to use), one per language pack. They are embedded into the exe via `src/flags.rc`.
Mapping: de-DE, en-GB, fr-FR, ka-GE, nl-NL, es-ES, el-GR, it-IT, ja-JP, ko-KR, pl-PL, pt-BR-BR, ru-RU, tr-TR, zh-Hans-CN.
Flags are only a visual hint; a language is not a country.
